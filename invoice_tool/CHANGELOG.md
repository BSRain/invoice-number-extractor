# 变更记录

## 1.13.0 — 2026-10-15

新增本地 `.invtask` 保存、打开与另存，保留完整记录和未确认草稿，包括人工框选候选、筛选及模式。打开任务不重新 OCR；原件缺失仍保留记录并支持确认、保存、全部 Excel 导出。保存不隐式确认草稿，切换任务前可保存、放弃或取消。

新增默认关闭的自动恢复，用户选择本机目录后启用。独立副本后台原子替换，每五秒合并近期改动，待写队列容量一；正常退出等待最终草稿写入，失败取消退出。恢复文件有保存时间和来源元数据，打开后另存，不自动覆盖原任务。副本保留由用户管理。格式为有界、校验和保护的明文 JSON，不嵌入原件，不接受网络路径，不上传。

176 项回归通过，覆盖任务往返、坏文件、缺失原件、写入失败保留旧副本、草稿和候选、同路径重开、持续改动定时保存、过期结果隔离和退出等待。反转恢复代次判断会被测试拒绝，随后恢复正式代码。运行验收范围包含真实 Tk / OCR、保存后关闭并在新会话打开、恢复副本、原件移动、全部 18 条 Excel 输出，以及便携 ZIP 的源码和模型校验。

原自动识别、金额规则、缓存及并行调度模块未修改；没有声称识别率或首次处理速度提升。本轮未重跑原有 25 条真实样例，仍未在全新 Windows 或物理混合 DPI 显示器验收。

## 1.12.0 — 2026-10-14

增加金额独立局部预览、缩放窗口、待处理/重复筛选、连续确认，以及人工框选区域重读。筛选后的 Excel 仍包含全部结果。

框选重读只产生人工复核候选；选择后先填入输入框，保存确认才更新记录。取消、推理失败、非法选区和保存校验失败保留原记录；原来已确认的金额不被自动修改。切换行保存与按钮确认共用同一保存流程，保留候选及定位。原自动识别、缓存与判重规则保持不变。

复核面板支持小窗口滚动及键盘焦点跟随。未加入任务保存、自动恢复、跨启动缓存和统一混合调度。

150 项回归测试通过，包含实际 Tk 筛选、连续确认、选区候选保存、保存前切换/放弃、取消及失败、已确认金额保护、真实拖框绑定和 980×640 窗口滚动。反转候选证据保存条件会被回归拒绝，已恢复正式实现。生成票面已实际验证金额缩放、旋转页拖框 OCR、明确选择与保存、双进程/页级并行及筛选后的全部 18 条 Excel 导出；便携包在交付时另行执行解压后验收。验收脚本在模拟弹窗操作前恢复自己的最小化窗口，并检查画布可见、尺寸稳定，避免向未显示的控件发送事件。

现有 25 条真实样例本轮未重新 OCR；原自动识别模块未修改，回归使用原单元测试和生成票面的真实 OCR。仍未在全新 Windows 电脑或物理混合 DPI 显示器验证。
